# 💧 Clean Water Quest - A Charity Water Game

An interactive educational game that teaches players about clean vs. contaminated water sources while raising awareness about Charity: Water's mission.

## Overview

Clean Water Quest is a simple web-based game designed to educate players about the importance of clean water access worldwide. Players must identify whether various water sources are clean or contaminated, learning about real-world water safety challenges in the process.

**Mission**: Nearly 2 billion people lack access to safe drinking water. This game aims to build awareness and understanding of the critical need for clean water infrastructure.

## Game Features

✨ **Interactive Gameplay**
- Quiz-based mechanic: Identify clean vs. dirty water sources
- Progressive difficulty across 3 levels
- Visual water representations
- Real-time scoring and feedback

📚 **Educational Content**
- 12 diverse water source scenarios
- Expert explanations for each answer
- Real-world context about water safety
- Link to Charity: Water's mission

🎮 **Game Mechanics**
- 3 lives system - choose carefully!
- Points system (10 points per correct answer)
- Level progression based on score
- Educational feedback explaining correct answers

## How to Play

1. **Start**: Click "Start Game" from the menu
2. **Decide**: Read the water source description
3. **Choose**: Click either "Clean Water" or "Dirty Water"
4. **Learn**: Read the explanation for the correct answer
5. **Progress**: Advance through levels and earn points
6. **Win**: Reach all 3 levels to complete the game

## Game Levels

- **Level 1**: Basic water contamination scenarios
- **Level 2**: Advanced sanitation and storage issues
- **Level 3**: Complex water infrastructure and sustainability

## Water Source Scenarios

The game includes scenarios such as:
- Wells near markets with sewage
- Certified treatment facilities
- Rivers downstream from industrial areas
- Hand pumps with filters
- Stagnant ponds with algae
- Solar-powered filtration systems
- And more realistic examples!
